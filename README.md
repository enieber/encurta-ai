# Encurta-ai

Encurta-ai é um projeto para facilitar o encuratamento de url para usuarios logados.

## Run in Production

required:
  - docker (podman)
  - docker-compose (podman-compose)

- copy env file with: `cp .env.sample .env`
- set values from .env
- run image with docker compose: `docker compose up -d`
